# 📚 Écosystème Gen-Plan & Skills

Ce dossier contient les skills et l'écosystème d'orchestration pour le PEK v4.1.

## 🚀 Skills Disponibles

### 1. esume-chat (v1.0.0)
Générateur de résumés structurés avec tracking des versions et Table des Matières (TOC) interactive.

####  Exemples d'utilisation

**Exemple 1 : Archivage d'un brainstorming**
> **Prompt :** *"Fais un résumé structuré de notre discussion sur les nouvelles fonctionnalités de l'app, en incluant la TOC."*
> **Résultat :** Génère un fichier .md avec la chronologie des idées, les décisions prises et les actions à entreprendre.

**Exemple 2 : Suivi de l'évolution d'un code (Versioning)**
> **Prompt :** *"Résume l'historique de nos échanges sur la refactorisation du module d'authentification, en suivant les versions du script."*
> **Résultat :** Un tableau chronologique montrant l'évolution du code (v1.0 → v1.1 → v2.0) avec les gains de performance à chaque étape.

**Exemple 3 : Transmission de projet (Onboarding)**
> **Prompt :** *"Crée un résumé détaillé de tout le projet PEK v4.1 pour un nouveau développeur, avec les optimisations clés."*
> **Résultat :** Un document d'onboarding complet listant l'architecture, les choix techniques et les leçons apprises.
