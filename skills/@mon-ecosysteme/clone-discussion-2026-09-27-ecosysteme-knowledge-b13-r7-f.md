### §3.3 Conventions établies (règle + exemple)

1. **Idempotence ×2** (D017) : toute écriture est rejouée à l'identique — ex. n60b 12/12 ×2 (fraîcheur Task 55), N30 11/11 ×2, fix audit no-op (sha16 stable).
2. **Arbitres AVANT action** (L003) : jamais de montée sans verdict mécanique préalable — ex. n60b ×2 avant boucle L005 ; garde pré-push A/B/C avant tout push.
3. **Recalibrage croisé AVANT certification** (L004) : toute écriture déclenche la mise à jour des arbitres dépendants — ex. validateur clone recalibré Task 55 (check4 D-1..D-N) avant validation du clone -f.
4. **Additivité R2** : ne jamais réécrire destructivement — historiques conservés (plans r5/r6/r7, PM par version, clones -a→-f, rapports T1/T2/T3 individuels).
5. **Worklog source de vérité** (R3) : chaque Task appendée (format SHARED §1.4) — ex. session Task 51 coupée par compression : constat d'honnêteté + reprise documentée.
6. **Persistance avant exécution** (R9) : scripts > 10 L sous `scripts/` avant exécution — ex. t51-*.py, t52-*.py, t54-prep-push.py.
7. **Contenu FR, identifiants non traduits** : docstrings/messages FR, noms de fichiers/fonctions conservés.
8. **Correct-py post-traitement** (GF-6 script-creator) : PEP 8/257 contrôlés à chaque script produit.
9. **Chaîne PDF complète scriptée** : tout PDF à couverture HTML passe par html2poster.js AVANT assemblage — ex. séquence t51-figures.py → html2poster.js → t51-consolidation.py (leçon Task 53).
10. **Secrets éphémères** : jeton en argument de commande, jamais écrit sur disque, masqué dans les sorties, remote restauré après usage, révocation recommandée — ex. t54-push.sh (PAT 1a0e0fff08caa30d).
